# NDC Model

This repository contains research notes and supporting artifacts for Noetic Diffusion Theory.

NDC stands for Noetic Descriptor Correlate.


## NDC scaffold

The `NDC/` package is a minimal synthetic dynamical system scaffold. It generates
latent trajectories and observations for downstream analysis. MNPS/MNJ computation is
intentionally **not** implemented here and must be performed via the external analysis repo.

## Observation Export v1 (analysis boundary)

Each run writes an observations file that contains only post-Observer outputs:

- `*_observations.h5` with datasets `t` and `Y` (plus optional `rhythm`, `control`, `win_t`, `win_Y`)
- JSON metadata in `attrs["metadata"]` with timebase and observer settings

Latent state is not included in the observations file. Latent trajectories remain in
`*_trajectory.h5` for simulator debugging only.

The analysis package lives in `ndc_analysis/` and reads the observations file without
importing `NDC.*`.

## Oracle Export v1 (simulator-only)

For benchmark harnesses and falsification checks, the simulator can optionally write a
separate oracle file:

- `*_oracle.h5` with datasets `t` and `X` (latent state), plus optional `regime`,
  `boundary_hit`, `rhythm`, and `control`
- JSON metadata in `attrs["metadata"]` with simulator configuration and provenance

This file is **not** used by `ndc_analysis/` and is intentionally separated from the
analysis boundary.

## Benchmark Standard (public)

Benchmarks are defined in `benchmarks/` with a versioned manifest schema (v0.1).
Reports are generated by `scripts/run_benchmarks.py` and written to
`reports/benchmark_v1.{md,json}`. New benchmarks must include a negative control and
an expected failure mode; see `benchmarks/CONTRIBUTING.md`.

## Quick run commands

```
python -m NDC.cli --config NDC/config/presets/baseline.yaml

python scripts/run_ndc_resolution_stress_grid.py --out-root outputs/resolution_stress
```
