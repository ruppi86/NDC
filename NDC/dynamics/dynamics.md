# dynamics

Core simulation and latent dynamics primitives.

## Scripts

- `boundary.py`: Latent space boundary handlers (e.g., reflecting box).
- `circulation.py`: Antisymmetric rotation terms for drift.
- `geometry.py`: Metric tensor support for latent spaces.
- `integrator.py`: Euler-Maruyama SDE integrator.
- `landscape.py`: Energy landscape definitions (potential functions).
- `plasticity.py`: Rules for landscape adaptation.
- `rvc.py`: Rhythmic Variance Control (noise gating).
- `scheduler.py`: Regime scheduling (e.g., wake/sleep cycles).
- `state.py`: Trajectory state containers.
- `__init__.py`: Package initialization.
