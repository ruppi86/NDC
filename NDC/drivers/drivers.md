# drivers

External input and rhythm drivers for NDC experiments.

## Scripts

- `base.py`: Protocol and state container for drivers.
- `composers.py`: Helpers for combining multiple drivers.
- `file_timeseries.py`: Driver that loads data from CSV or JSON files.
- `inputs.py`: Simple slow-timescale control input drivers (e.g., step).
- `oscillators.py`: Fast-timescale rhythmic drivers (e.g., sine wave).
- `surrogates.py`: Surrogate drivers for timing counterfactual tests.
- `__init__.py`: Package initialization.
