# io

Input/Output and serialization for NDC experiments.

## Scripts

- `observation_export.py`: Analysis-facing HDF5 export for observed data.
- `oracle_export.py`: HDF5 export for full latent state (oracle) data.
- `results.py`: JSON serialization for experiment summaries and comparisons.
- `trajectory.py`: HDF5 serialization for full latent trajectories.
- `__init__.py`: Package initialization.
